# Car database (`app/src/main/assets/cars/`)

One JSON file per diagnostic family: `<family>.json` (hand-curated: brands, models, parameters) and
`obdb/<family>.json` (generated by `tools/cars/obdb_import.py` from github.com/OBDb, parameters only).
The app loads them all and merges by family; a curated parameter wins over an OBDb one with the same
request + signal id.

Rule (same as the help texts): only what a concrete public source says or what was seen on a car.
Every model and every parameter has `src` (URLs). Unknown → leave the field out, never guess.

## Family ids

`gm vag toyota hyundai lada renault nissan ford mazda bmw mercedes honda mitsubishi subaru suzuki china`

## File

```json
{
  "family": "toyota",
  "title": "Toyota / Lexus",
  "brands": [
    { "name": "Toyota", "wmi": ["JT", "4T", "5T", "2T", "SB1", "NMT", "XW7"] },
    { "name": "Lexus",  "wmi": ["JTH", "JTJ", "2T2"] }
  ],
  "models": [ ... ],
  "commands": [ ... ],
  "features": [ { "ru": "…", "en": "…" } ]
}
```

`wmi` — VIN prefixes (2 or 3 chars); the longest match wins across all files.
`features` — short lines for the guide: what this app reads on this make beyond standard OBD.

## Model (one entry per generation)

```json
{
  "brand": "Toyota",
  "model": "RAV4",
  "gen": "XA20",
  "years": [2000, 2005],
  "vin": ["^JTE..20V", "^JTMZD3"],
  "engines": [
    { "code": "1AZ-FE", "liters": 2.0, "cyl": 4, "fuel": "petrol", "maf": true }
  ],
  "protocol": 6,
  "obd": "left_door",
  "buses": { "ru": "…", "en": "…" },
  "note":  { "ru": "…", "en": "…" },
  "src": ["https://…"],
  "verified": false
}
```

- `vin` — optional regexes over the full VIN that identify this model (only if a source gives the VDS).
- `fuel`: `petrol | diesel | hybrid | electric | lpg`. `maf`: true/false, leave out if unknown.
- `protocol` — ELM327 ATSP number of the engine ECU for this generation:
  1 J1850 PWM, 2 J1850 VPW, 3 ISO 9141-2, 4 ISO 14230 5-baud, 5 ISO 14230 fast, 6 CAN 11/500,
  7 CAN 29/500, 8 CAN 11/250, 9 CAN 29/250. If years split between protocols — two entries, or leave out.
- `obd` — where the socket is, one of the shared pictures:
  - `left_door`      under the dash, left of the column, towards the door / hood release
  - `under_column`   right under the steering column
  - `right_of_column` under the dash between the column and the centre console
  - `left_cover`     left of/under the column behind a fuse-box or trim cover (remove it)
  - `console`        in the centre console / under the ashtray / behind a tunnel trim
  - `passenger`      passenger side / glovebox
- `verified: true` only for cars actually connected with this app (CTS 2.8, Polo, RAV4 2005, Vesta, Solaris).

## Command (one request, one or more values out of its answer)

```json
{
  "hdr": "7E0",
  "rsp": "7E8",
  "svc": "21",
  "did": "01",
  "rate": "medium",
  "models": ["RAV4"],
  "signals": [
    {
      "id": "TOY_ECT",
      "name": { "ru": "Температура ОЖ", "en": "Coolant temp" },
      "unit": "°C",
      "dec": 0,
      "group": "main",
      "fmt": { "bix": 0, "len": 8, "mul": 1, "div": 1, "add": -40, "signed": false },
      "conf": "?",
      "src": ["https://…"],
      "note": "optional, for the maintainer"
    }
  ]
}
```

- CAN only, 11-bit ids (3 hex chars). `rsp` defaults to `hdr + 8`.
- `svc`: `"22"` (2-byte `did`, 4 hex chars) or `"21"` (1-byte, 2 hex chars). Read-only services only;
  default diagnostic session only — nothing that needs `10 03`, security access or routines.
- `rate`: `fast` (follows pedal/shifts), `medium`, `slow` (counters, wear, temps of big masses).
- `models` — optional: model names (as in `models[].model`) this command is known on. Omit = whole family.
- `years` — optional `[from, to]` model years it is known on (OBDb filters). Omit = any.
- `fuel` — optional `["diesel"]` / `["petrol"]`: sent only when the car is known to be on that fuel (PID 51
  or all engines of the picked model). Use it whenever the same DID means something else on other ECUs
  (VAG 114F: soot on EDC17, misfires on a petrol ECU).
- `engines` — optional engine code substrings (`["EA888"]`) the command is known on: on a car with other
  or unknown engines it is still probed, but its values are shown as unverified "(?)".
- A command known only on other models of the family is probed too (after this model's ones); its values
  are always shown as "(?)".
- `fmt` — the value: take `len` bits starting at bit `bix` of the answer **data after the echo**
  (after `62 DID DID` / `61 ID`), big-endian, bit 0 = MSB of the first data byte;
  raw → signed if `signed` → `raw * mul / div + add`. `le: true` — little-endian (whole bytes only).
  `poly: [c0, c1, c2, …]` — instead of mul/div/add: `c0 + c1·raw + c2·raw² + …` (Nissan JATCO CVT temp). `map` (optional): `{ "0": {"ru": "P", "en": "P"}, … }`
  turns a raw value into text.
- `role` (optional, set it whenever it fits) — what the value is, so the main screen shows it in the
  right card on any make: `oil_temp oil_pressure oil_life oil_level atf_temp cvt_temp clutch_temp
  cvt_wear gear tc_slip input_rpm output_rpm fuel_level_l odometer battery_soc battery_temp
  knock_retard boost dpf_soot service_km service_days hv_soc hv_soh`.
- `group`: `main` (worth a card on the main screen), `fuel` (fuel tab), `other` (all data only).
- `conf`: `"OK"` — two independent sources agree or seen on a car; `"?"` — one source / conflicting.
- Units: `°C kPa bar V A % rpm km/h km L ms ° s h` (metric; convert from psi/°F/miles in `mul/add`).
